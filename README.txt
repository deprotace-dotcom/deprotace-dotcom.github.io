DE PROTACE WEBSITE UPDATE

Files:
- index.html: updated website, SEO metadata and social sharing buttons
- sitemap.xml: sitemap for search engines
- robots.txt: allows search engines to crawl the public website

HOW TO PUBLISH:
1. Open your GitHub repository: deprotace-dotcom.github.io
2. Upload these three files to the repository root.
3. If GitHub asks what to do with index.html, choose to replace/overwrite the existing file.
4. Commit changes.
5. Wait for GitHub Pages to deploy, then visit https://deprotace-dotcom.github.io/

IMPORTANT:
- Keep the repository public and GitHub Pages set to main / (root).
- Google indexing is not instant. After publishing, submit
  https://deprotace-dotcom.github.io/sitemap.xml in Google Search Console.
